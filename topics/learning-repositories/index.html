GitHub repositories to learn robotics

Robotics learning repositories organise papers, tutorials, algorithms, coursework and code examples in one place. They are useful when you need a structured route into topics such as localisation, planning, perception or machine learning instead of another isolated product tutorial and want to practise deliberately.

Direct answer

What belongs in this collection?

Use these repositories after you can run a basic robot or simulator workflow. Choose one topic, reproduce a small code example, and record what you learned before opening another list. This keeps broad collections from becoming passive bookmark archives over time.

How to use these resources

  1. Skim the list and open two or three links that match your current level.
  2. Prefer resources with active documentation or recent commits when you need production guidance.
  3. Combine one tutorial source with one simulator and one small project rather than collecting endless bookmarks.
