Direct answer

What is the best place to start learning robotics online?

Start with one free university course, practise in a robotic simulator, then clone a small open-source robot project. Add ROS 2 tutorials once you can run a documented demo. This library groups those starting points so you do not have to invent the path yourself.

FAQ

Common questions

What is Get Into Robotics?

Get Into Robotics is a free curated library of robotics learning resources with 99 links across 8 collections, maintained by Akshet Patel.

How should a beginner start learning robotics?

Finish one structured course, practise in a simulator, then reproduce a documented open-source robot demo before buying hardware. Start with the how-to-learn-robotics guide.

Should I learn ROS or ROS 2 first?

New learners should usually start with ROS 2. Use classic ROS materials when a course or legacy stack still depends on ROS 1.

Which robotic simulator should I try first?

Gazebo and Webots are common starting points for ROS-centric learning. MuJoCo suits research and reinforcement learning. Isaac Sim suits high-fidelity NVIDIA workflows.
