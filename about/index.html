About Get Into Robotics

Get Into Robotics is a curated library of robotics learning resources edited by Akshet Patel. It exists to shorten the path from curiosity to a clear next tutorial, course, project or simulator.

Last updated 2026-07-29

Direct answer

Who is behind this site?

Get Into Robotics is maintained by Akshet Patel, a robotics practitioner and educator. The public source list lives on GitHub, where anyone can suggest improvements.

Curation principles

  • Prefer resources that a motivated learner can use without expensive proprietary lock-in.
  • Group links by intent: build, study, watch, simulate or read.
  • Keep descriptions honest. Inclusion is not a claim that every third-party page is perfect.
  • Review broken links when reported through the GitHub repository.

Trust and transparency

  • No affiliate book promotions are shown on this site.
  • External destinations keep their own licences, pricing and privacy policies.
  • Microsoft Clarity is used for anonymised usage analytics on the homepage experience.
  • British English is used for original site copy.

Contact

For corrections or additions, open an issue or pull request on the robotics-resources repository. For other enquiries, visit akshetpatel.com.
