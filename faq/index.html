Robotics learning FAQ

Short answers to the questions beginners and career changers ask most often when they start robotics.

What is Get Into Robotics?

Get Into Robotics is a free curated library of robotics learning resources. It organises projects, ROS and ROS 2 materials, courses, books, YouTube playlists and simulators so learners can find a credible next step quickly.

How should a complete beginner start learning robotics?

Start with one structured course, one simulator and one small project. The how-to-learn-robotics guide on this site recommends that sequence and links into the relevant collections.

Should I learn ROS or ROS 2 first?

New learners should usually start with ROS 2, because it is the actively developed generation of the framework. Use the ROS collection mainly when a course or legacy stack still depends on ROS 1.

Which robotic simulator should I try first?

Gazebo and Webots are common starting points for ROS-centric learning. MuJoCo is popular for research and reinforcement learning. Isaac Sim is stronger when you need high-fidelity NVIDIA workflows.

Are the linked books and courses free?

This library prioritises resources that are freely browseable or widely used in education. Always check the destination site for licence terms, enrolment requirements or download conditions.

How often is the library updated?

The collections are reviewed periodically and when the community reports broken links. Each topic page shows a last-updated date, and the GitHub repository tracks proposed changes.

Can I suggest a new resource?

Yes. Open an issue or pull request on the GitHub repository with the URL, a short description and the collection it belongs in.

Is Get Into Robotics affiliated with ROS or Open Robotics?

No. The site is an independent educational directory. Names such as ROS, Gazebo and Autoware belong to their respective organisations.
